# Miles Command Center

Personal dashboard for funding award trips from Indian credit card points (Axis Atlas, HSBC TravelOne, ICICI Times Black → Air India, Flying Blue).

Static build of a Claude artifact, hosted on GitHub Pages.

- Balances and planned spends you edit are saved in your own browser (localStorage), not in this repo or shared between visitors.
- Tailwind is precompiled into `styles.css`; React 18.3.1 loads from unpkg.
